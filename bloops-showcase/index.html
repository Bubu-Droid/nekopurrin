def collatz(n):
    steps = 0
    while n != 1:
        n = n // 2 if n % 2 == 0 else 3 * n + 1
        steps += 1
    return steps

Theorem (Pythagoras). In a right triangle, $a^2 + b^2 = c^2$.
Proof. Rearrange four copies of the triangle inside a square of side $a + b$.□
Lemma. Every tree with $n$ vertices has $n - 1$ edges.
Proposition. $\sqrt{2}$ is irrational.
Corollary (of the lemma). A forest with $c$ components has $n - c$ edges.
Example. $3, 10, 5, 16, 8, 4, 2, 1$ is a Collatz sequence.

Problem (AMC-style). Find the remainder when $2^{10}$ is divided by $7$.
